# ecommerce-mickael-douglas

Disciplina: Desenvolvimento Web em HTML5, CSS, JavaScript e PHP

## O que foi feito
- Página inicial com menu, vitrine  produtos e formulário de contato
- CSS responsivo (celular, tablet e notebook)
- JavaScript: frete, menu e validação do formulário

## Como abrir
1. Baixe o projeto (botão verde Code > Download ZIP) e descompacte
2. Abra a pasta no VS Code
3. Clique em Go Live (Live Server) e a página abre no navegador
